# Linux Command Line Practice
## Сортировка и подсчет строк (sort +  uniq -c)
Связка для анализа текста и логов (сортировка обязательна, так как uniq считает только соседние строки):
'''bash
cat access.txt | sort | uniq -c > access2.txt

## Фильтрация текста через конвеер (grep)
'''bash
cat processes.txt | grep "nginx" >filtered_processes.txt

31.10.2026
## Фильтрация логов с ограничением по количеству строк (cat + grep + tail)
'''bash
cat /var/log/syslog | grep -i "error" | tail -n 10 > errors_report.txt
